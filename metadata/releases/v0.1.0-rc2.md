# FEATS data v0.1.0-rc2

This prerelease provides the complete Phase 1 corpus and the corresponding
experimental Phase 2 cleaned and Phase 2b consolidated corpora in three
access-controlled assets. The repository and its Releases are private.

## Phase 1: normalized data

- 29 JSONL files
- 1,454,003 original-simplification pairs
- 12 languages
- Sources: MultiSim, Align-and-Shine, SimplifyUR, iDEM, and Saaq al-Bambuu
- Preserved upstream split metadata
- Embedded `NORMALIZED_MANIFEST.csv`

## Phase 2: experimental cleaned data

- 29 JSONL files
- 859,550 retained pairs (59.12%)
- 594,453 removed pairs (40.88%)
- Embedded `CLEANED_MANIFEST.csv`

The removal rate remains substantially above the initial expectation, so
Phase 2 is an experimental cleaning candidate rather than the final recommended
training selection.

## Phase 2b: exact-pair consolidation

- 12 JSONL files, one per language
- 854,486 canonical original-simplification pairs
- 859,550 surviving Phase 2 observations represented in provenance
- 5,064 redundant exact-pair observations consolidated
- 22 pairs retained from only a subset of their Phase 1 occurrences
- Embedded `CONSOLIDATED_MANIFEST.csv`
- ZIP size: 194,083,694 bytes
- ZIP SHA-256: `95920a482dfb37cb71c954457c1cf166c7c18aeb89aa42b5c17b36da7ef01608`

## Access and reuse

iDEM and Saaq al-Bambuu are included for authorized project collaborators.
Private repository visibility does not change upstream ownership, copyright,
or licence terms. Do not redistribute these assets outside the project.

GitHub displays a SHA-256 digest for each uploaded ZIP. Each ZIP also contains
a manifest with per-file counts and hashes.
