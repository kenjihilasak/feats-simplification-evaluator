# FEATS complete pipeline v0.2.0-rc2

This private prerelease contains the complete outputs of the FEATS data
pipeline across 12 languages. Each phase is distributed independently with an
embedded audit manifest.

| Phase | Product | Records | Asset |
|---|---|---:|---|
| Phase 1 | Normalized source observations | 1,454,003 | `feats-phase1-normalized-v0.2.0-rc2.zip` |
| Phase 2a | Experimentally cleaned observations | 859,550 | `feats-phase2a-cleaned-v0.2.0-rc2.zip` |
| Phase 2b | Consolidated canonical pairs | 854,486 | `feats-phase2b-consolidated-v0.2.0-rc2.zip` |
| Phase 3a | Strategy predictions and full analysis | 2,563,458 | `feats-phase3a-strategy-detection-v0.2.0-rc2.zip` |
| Phase 3b | Word-alignment v2 sidecars | 854,486 | `feats-phase3b-word-alignment-v0.2.0-rc2.zip` |

## Changes from rc1

Phase 3a now includes a reproducible full-corpus analysis answering the mean
number of detected strategies per pair by language and by source within each
language. It also reports the 0–6 strategy-count distribution, strategy
prevalence and mean scores, source/corpus breakdowns, and pairwise agreement
between the three models. The other phase assets are unchanged from rc1.

Detailed methods and results are documented in each phase README.
