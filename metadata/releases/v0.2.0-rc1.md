# FEATS complete pipeline v0.2.0-rc1

This private prerelease contains the complete outputs of the FEATS data
pipeline across 12 languages. Each phase is distributed independently with an
embedded audit manifest.

| Phase | Product | Records | Asset |
|---|---|---:|---|
| Phase 1 | Normalized source observations | 1,454,003 | `feats-phase1-normalized-v0.2.0-rc1.zip` |
| Phase 2a | Experimentally cleaned observations | 859,550 | `feats-phase2a-cleaned-v0.2.0-rc1.zip` |
| Phase 2b | Consolidated canonical pairs | 854,486 | `feats-phase2b-consolidated-v0.2.0-rc1.zip` |
| Phase 3a | Strategy predictions from three models | 2,563,458 | `feats-phase3a-strategy-detection-v0.2.0-rc1.zip` |
| Phase 3b | Word-alignment v2 sidecars | 854,486 | `feats-phase3b-word-alignment-v0.2.0-rc1.zip` |

Phase 1, Phase 2a and Phase 2b are unchanged from `v0.1.0-rc2` and are
republished here so collaborators can download the complete pipeline from one
release. Detailed methods and results are documented in each phase README.

## Access and reuse

This repository and its releases are private and access-controlled. Upstream
copyright, attribution and reuse restrictions still apply. In particular, do
not redistribute iDEM or Saaq al-Bambuu data outside the project without the
required permission.
