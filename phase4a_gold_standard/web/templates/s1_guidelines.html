S1 annotation guidelines

Judge only the named axis. Labels X, Y and Z are random. Work independently: the optional AI suggestion can be wrong.

OMIT

The simplified text should leave out unnecessary detail. A worse version has an unnecessary detail back.

SYN

The text should use simple words. A worse version has a harder word back.

EXPL

Difficult terms should be explained. A worse version has an explanation removed.

MOD

Information should be ordered so it is easy to follow. A worse version puts the main point late or uses a confusing sentence order.

ILLOC

The text should keep the right kind of utterance and certainty. A worse version may turn a statement into an instruction or make it uncertain.

Worked examples

  • OMIT: a focused sentence ranks above one with a restored date, which ranks above one with two unnecessary details.
  • SYN: “use a helpful method” ranks above “utilize a helpful method”, then “utilize a beneficial methodology”.
  • EXPL: “tachycardia (a fast heartbeat)” is better than the unexplained term; equally useful explanations tie.
  • MOD: introducing Marie before using “she” is better; a clear introduction ranks above one confusing fronting change, then reversed sentences.
  • ILLOC: “Water boils” is better than “Water might boil”; a plain statement is better than an added “Remember that …” instruction.

How to answer

For a pair, select the better version or Same. For three versions, assign 1 to best and 3 to worst; equal numbers are ties. Report meaning, fluency or other changes separately. Use the note field when uncertain.
